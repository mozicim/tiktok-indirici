# Video İndirici

TikTok, Instagram, YouTube, Facebook ve diğer video bağlantılarını indirmek için küçük bir PWA. Marka: @mozicim.

**Sadece kendi videoların veya izin aldığın videolar için kullan.**

Canlı adres: https://mozicim.github.io/tiktok-indirici/

Bu sayfa platformlara doğrudan bağlanamaz; ücretsiz üçüncü taraf servislere (TikTok için tikwm, diğerleri için GenDownload) başvurur. Servis durursa indirme çalışmayabilir.
