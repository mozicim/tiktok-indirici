# TikTok İndirici

Filigransız TikTok videosu indirmek için küçük bir PWA. Marka: @mozicim.

**Sadece kendi videoların veya izin aldığın videolar için kullan.**

Canlı adres: https://mozicim.github.io/tiktok-indirici/

Bu sayfa TikTok’a doğrudan bağlanamaz; ücretsiz bir üçüncü taraf servise (tikwm, yedek olarak GenDownload) başvurur. Servis durursa indirme çalışmayabilir.
